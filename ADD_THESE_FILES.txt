APEX OANDA - FILES TO ADD (app.py is intentionally not included)

1. In your GitHub repository, create these folders if they do not already exist:
   agents
   data
   tests
   .streamlit

2. Add each file in this package to the matching folder, keeping the exact names.
3. Do NOT upload a real .streamlit/secrets.toml file to GitHub.
   The secrets.toml.example file is only a template.
4. Add your OANDA API token later in Streamlit Community Cloud > App > Settings > Secrets.
5. Start with OANDA practice mode.
